Getting Started

Your first job in STRUK

The fastest way to learn STRUK is to document one real project from start to finish.

1

Create the project

Add the job name, client, address, dates, and the basic information you want attached to the project record.

2

Break the job into areas

Create rooms, exterior sections, systems, or other areas so photos, videos, notes, and work items stay organized.

3

Document Before, During, and After

Capture or add jobsite photos and videos as work progresses. Organize media by area and stage so the job tells a clear visual story.

4

Run the punch list

Create work items, set priority and status, assign crew when needed, add due dates, notes, materials, labor notes, and client-requested items.

5

Build the paper trail

Use proposals, contacts, calendar items, activity history, and project notes to keep decisions and job progress easy to follow.

6

Generate the report

Build a professional PDF report from the project record. Review it, then share, save, email, text, or print it using your device.

A simple STRUK rhythm

Document the job → Organize it → Assign it → Communicate it → Prove it.

Helpful tips

  • Use clear area names that make sense to anyone reading the final report.
  • Capture “before” photos before work starts whenever possible.
  • Update punch-item statuses as work changes so Activity History stays meaningful.
  • Review proposals and reports before sending them to a client.
  • Keep internal notes separate from client-safe information when the app gives you that choice.
